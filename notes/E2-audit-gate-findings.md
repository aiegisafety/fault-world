# E2 修正版：严格性 × 行动门槛（OFF / SELF / AUDIT）

日期：2026-08-25 ｜ 模型：`qwen3.7-flash`（阿里云工作空间端点） ｜ **每格 n=3–4，共 25 run**
代码：`code/run_2x2.py`（gate 三档）、`code/audit_gate.py`（审计与 oracle）、`code/analyze_2x2.py`

> 仍是试点。n≤4，无置信区间。以下数字用于判断设计是否可测，不能进论文。

## 两处设计修正（上一轮发现的问题）

1. **VERIFIED 不再采信模型自报。** harness 从真实干预记录重算地位：
   做过 `do(cause=ACTIVE)` 且效应 ≥14/20，或做过 `do(cause=INACTIVE)` 且效应 ≤6/20 才算通过
   （两个阈值的单侧假阳性率均为 P(X≥14|p=0.5)=0.058；真规则 p=0.90，巧合 p=0.50）。
   门槛三档：
   - `OFF` 诊断可用全部信念规则
   - `SELF` 只可用模型自报 VERIFIED 的规则（上一轮的做法）
   - `AUDIT` 只可用 harness 审计通过的规则
2. **诊断任务加了 oracle 上限。** 实测拿着真规则集的算法上限只有 **0.81**
   （真效应有 10% 概率不出现，两条真效应也会同时出现）。因此同时报
   「全部 case」与「oracle 可答子集」两个准确率，后者上限为 1.00。
   上一轮没有这个标尺，准确率差异根本无法解读。

## 三条与假设直接相关的观察

**T1（权衡存在性）——方向一致。**
把严格性从 LOW 提到 HIGH：信念集里的巧合从 2.25 降到 2.50→1.00（AUDIT 档 3.00→1.00），
但同时 recall 从 1.00 掉到 0.89–0.92，**审计能通过的真规则从 1.00 掉到 0.56–0.75**，
干预次数也从 6.0 降到 4.0。
即：谨慎的 agent 不只是少写了几条假规则，它**少做实验、少发现、能证实的东西更少**。
这正是 Paper 1 主张的"谨慎有代价"。

**T2（行动门槛外推前沿）——本轮得到支持，而且是最干净的一格。**
`LOW/AUDIT` 同时拿到全表最高的信念规模（9.0 条，其中 3.00 条是巧合，即最"迷信"的信念集）
**和**全表最高的诊断表现（可答子集 1.00，全 case 0.91，后者已超过 oracle 全 case 上限 0.81
——因为审计规则集帮它在部分模糊 case 上也蒙对了）。
换句话说：**让 agent 大胆持有假设、但只允许依据审计通过的规则行动，
比让它一开始就不敢想更好。** 这是 T2 预测的前沿外推，也是 Epistemic Lineage 的真正用武之地。

对照 `LOW/SELF`（0.81）说明门槛的效力**完全取决于地位标签是否可信**：
同样是"只用 VERIFIED"，采信模型自报就没有收益，改由 harness 审计才有。

**Goodhart 效应——在本模型上比 glm 弱但同向。**
`HIGH/OFF` 平均 0.50 条伪 VERIFIED，`LOW/OFF` 为 0.00。
上一轮 glm-4.5-air 在 HIGH/OFF 上是 1.33。两个模型都是**越要求严格，越爱贴 VERIFIED 标签**。

## 与上一轮（glm-4.5-air）的差异

qwen3.7-flash 整体比 glm 更"正常"：信念集更小、伪标签更少、诊断更准。
说明**这些量是模型相关的**，正式实验必须跨模型，不能用单模型下结论。

## 目前的证据强度（诚实说明）

- 每格 n≤4，效应量未估计，没有任何统计检验。
- 只有一个模型的一套参数。
- `LOW/AUDIT` 的 1.00 是 4 个 run 的平均，天花板效应明显，需要更难的诊断任务来拉开区分度。
- 因此：**这些结果只证明"设计能测出想测的东西"，不证明任何假设成立。**

## 基础设施

- 阿里云工作空间端点 key 的免费额度在本轮末也耗尽（HTTP 403 FreeTierOnly），
  8 个 run 停在半途（检查点已存，补上额度即可续跑）。
- 智谱 key 可用但有账户级速率限制（429/1302），实测并发上限 4–5。
- **结论：正式 E1 规模（3 模型 × 5 档 × 40 run）在免费额度下不可能完成，必须先解决付费额度。**
